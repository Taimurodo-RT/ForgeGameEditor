# ИИ жителей

Utility AI для жителей: они сами едят, спят, работают, празднуют и реагируют на мир, а игрок управляет приоритетами, расписаниями и постройками. Это модуль Forge: рантайм будет crate `forge-villagers` в `rust/`, редактор будет вкладкой «Жители».

| Файл | Что в нём |
| --- | --- |
| [spec.md](spec.md) | Как жители принимают решения, события, реакции, нодовые графы, вкладка редактора, план |
| [data-model.md](data-model.md) | Формат файлов в `game/villagers/`, манифест, снимок, журнал, коды ошибок |
| [graphics-spec.md](graphics-spec.md) | Векторная графика вкладки «Жители», которую рисуем в Motif |

Спецификацию Роман составил 28.10.2026 для Godot и отдельного редактора на Tauri. 30.10.2026 он решил, что ИИ становится частью Forge, а привязку к Godot убираем полностью. В конце каждого файла есть раздел «Изменения от 30.10.2026».
