# Модели шагов для ревью

Здесь копии моделей из файлов проекта, которые ревьюер должен прочитать вместе с PR: модель записывается до кода, а
после кода в ней дописан раздел «Как сделано». Рабочая копия каждой — в файлах проекта, путь назван в начале файла.

- [14.3c-шаблон-модель.md](14.3c-шаблон-модель.md) — шаблон «Три в ряд» и сквозной сценарий автора (PR #91).
- [14.3c-ТЗ-картинки.md](14.3c-ТЗ-картинки.md) — ТЗ на картинки шаблона «Три в ряд»; первый недостающий ассет
  `рубин.png` описан в модели, раздел «Картинки: недостающий ассет».
- [изображения-модель.md](изображения-модель.md) — вкладка «Изображения», первая рабочая версия (следующая после 14.3c).
- [вектор-модель.md](вектор-модель.md) — векторная графика: ThorVG в «Пиксельных», lunasvg в интерфейсе, общий
  морфинг; шаг 1 — модуль `engine/vector` (PR #94).
- [движение-модель.md](движение-модель.md) — анимация «Пиксельных» кодом и на таймлайне, свой Motion Canvas для
  игр; шаг 1 — ядро записи клипов и правки кода (PR #99).
