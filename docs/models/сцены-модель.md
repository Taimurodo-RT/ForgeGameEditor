# «Сцены»: кат-сцены и живые экраны из персонажей (шаг 6 «Векторной») — модель

> Копия файла проекта `editors/сцены-модель.md` для ревью в PR (2026-10-19). Рабочая копия — в файлах проекта.

Записана до кода. Версия 1, 2026-10-19: первая; главный выбор (вопрос 1 ниже) ждёт Романа, работа идёт по
рекомендованному ответу. Это шаг 6 модели [движение-модель.md](движение-модель.md): там раздел «"Сцены" — следующая

## Откуда задача

- Решение 4 движения (Роман, 2026-10-14): «Сцены» (кат-сцены, анимированные экраны) — отдельной моделью после шагов 1–5.
- Раздел «"Сцены" — следующая модель» движения: несколько рисунков с их клипами и картинки PNG; камера (сдвиг,
  приближение, поворот, движение по кривой); музыка под всей сценой и звуки; экранные переходы «сдвиг»,
  «приближение», «растворение» и свои; `wait_action("Действие")`; в игре нода «Логики» «Показать сцену» и Luau
  `forge.scene.play`.
- Карта Motion Canvas в движении, «Сцены, переходы, камера, звук, презентация»: `Camera` (`centerOn`, `zoom`,
  `followCurve`), `Img`, музыка, экранные переходы (`slideTransition`, `zoomInTransition`, `fadeTransition`,
  `useTransition`), `finishScene`, `beginSlide`.
- Образец Романа (2026-10-17, «Vector Motion»): над холстом «Орбита / Сцена 01», холст 1920 × 1080, «6 секунд»,
  слева «Слои / Ресурсы». Таблица «Что из образца куда» движения: «Список сцен, полоса сцен» — шаг 6.

## Что уже есть и на что сцена ложится

- **Персонаж** «Векторной»: рисунок кодом (`draw`) или SVG из «Ресурсов», другие рисунки (`drawings`), клипы
  (`clips`) кодом в стиле Motion Canvas, параметры, зерно. Запись клипа — дорожки «часть · свойство» с блоками, кадр в
  любой миг сразу (шаг 1); правки мышью пишут в код (3б); просмотр, звук (3в); всё рисование шага 4.
- **На экране игры** (шаг 5): «Отдать экрану» пишет `Имя.svg` и `Имя.motion.json`; слой экрана играет клип
  (`ui.svg_play`) по часам экранов, с метками, сменой рисунка, смешиванием клипов и параметрами из игры.
- **Экраны игры** (`engine/game/screens.h`): страницы поверх мира с ролью, вписыванием в экран игрока
  (`forge-fit`), паузой мира (`forge-pauses`), музыкой экрана (`forge-music`, одна музыка — самого верхнего экрана),
  Esc, действиями кнопок («показать», «разговор» …).
- **«Ввод»**: действия модуля («Прыжок», «Поговорить» …) и оболочки («Пауза» — Esc, «Журнал», быстрые сохранения).
- **Разговоры «Сюжета»**: игра открывает разговор по имени (действие кнопки «разговор»).

## Решения

Вопрос Роману — один, остальное решено по образцу и по тому, как уже устроены экраны игры; каждое решение меняется
по слову Романа.

1. **Что такое сцена** — вопрос Роману (карточка 2026-10-19). Рекомендую: **свой мультфильм поверх игры** — сцена
   рисует свои рисунки и картинки своей камерой на экране игры, мир под ней стоит (или идёт, если так сказано). Другой
   ответ: сцена ещё и двигает героя, объекты уровня и камеру игры («кат-сцена в мире»); тогда шаг вырастает примерно
   вдвое, и живого вектора у объектов уровня до GPU-слоя нет (движение, «Не в этой версии»), так что в мире двигались
   бы спрайты. По рекомендации кат-сцена в мире — отдельная модель после шага 7.
2. **Где делается** — в той же «Векторной», как в образце: в левой панели рядом с «Персонажами» список **«Сцены»**
   («Новая сцена»), путь над рабочей областью «Сцены / Вступление». Код, плеер, таймлайн, консоль, история и клавиши
   — те же, что у персонажа.
3. **Код сцены — как код персонажа**: раздел `stage` (что на сцене, как `draw`) и раздел `scene` (что происходит,
   как клип); те же функции потока, переходы свойств, сглаживания, `wait_until`, `sound`, `emit`, `log`, `params`.
   Новое — актёры, картинки, камера, музыка, переходы, ожидание игрока и разговор.
4. **Актёр** — персонаж из «Персонажей» на сцене: двигается целиком, играет свои клипы (`play`, `loop`) и слушается
   по частям. Клип персонажа в сцене — тот же, что в игре: правится у персонажа, сцена его только ставит во времени.
5. **В игре сцена — экран поверх всего**, вписанный в экран игрока, как страницы «Интерфейса» (по умолчанию «целиком,
   с полосами»). Мир по умолчанию на паузе; «Пауза» (Esc) открывает меню паузы с пунктом «Пропустить сцену», если сцене
   можно пропускаться (по умолчанию можно). Сохраниться во время сцены нельзя (быстрое сохранение говорит почему),
   загрузка сцену кончает; сохранения сцен не помнят.
6. **Ожидание игрока** — `wait_action("Поговорить")` ждёт действие «Ввода»; `wait_action()` без имени — любую клавишу,
   кнопку мыши или геймпада. Пока сцена ждёт, её время стоит, а повторы актёров (`loop`) идут дальше.
7. **Текст в сцене — разговорами «Сюжета»**: `talk("Встреча")` открывает разговор игры поверх сцены и ждёт его конца.
   Своего текста у сцены нет (как у персонажа: текст — «Интерфейс»); титры — картинкой или рисунком.
8. **Сцены друг за другом** — «Логикой»: у ноды «Показать сцену» выход «Когда кончилась»; новая сцена, показанная в
   тот же миг, входит своим переходом с последнего кадра прежней. Переход сцены — как она входит; `leave` — как она
   уходит обратно в игру.

## Сцена в двух словах

```lua
-- «Вступление»: ёжик идёт к скакуну, камера едет за ним, разговор, скакун прыгает.
return {
  params = { speed = 1 },
  stage = function(p)
    canvas(1920, 1080)
    picture("лес", "картинки/лес.png", { x = 0, y = 0, w = 1920, h = 1080 })
    actor("ёжик", "персонажи/Ёжик", { x = 300, y = 900, scale = 6, pivot = { 16, 48 } })
    actor("скакун", "персонажи/Скакун", { x = 1500, y = 900, scale = 6, pivot = { 16, 48 } })
    path("дорога", { d = "M 300 900 Q 900 860 1300 900", hidden = true })
  end,
  scene = function(p)
    transition("растворение", 0.5)          -- как сцена входит
    music("тема леса", { fade = 1 })
    actor("скакун"):loop("idle")             -- качается, пока его не позовут
    all(actor("ёжик"):along("дорога", 3 / p.speed, "linear"),
        actor("ёжик"):loop("walk"),
        camera():follow(actor("ёжик")))
    actor("ёжик"):play("idle")
    camera():zoom(1.4, 0.8, "in_out_cubic")
    wait_action("Поговорить")
    talk("Встреча")
    actor("скакун"):play("jump", { params = { height = 14 } })
    emit("знакомы")                          -- сообщение «Логике»
    leave("растворение", 0.6)                -- как сцена уходит в игру
  end,
}
```

## Файлы

- **Сцена в проекте**: `сцены/Вступление.luau` (код) и `сцены/Вступление.scene.json` (то, что тянут мышью и что не
  код: длины событий времени, диапазон, кадров в секунду, зерно, как у `.pixel.json` персонажа) — в «Ресурсах»,
  новая сцена «Сцена», «Сцена 2» …. Картинки и персонажи — свои файлы «Ресурсов», сцена ссылается на них путём.
- **Сцена в игре**: «Отдать игре» пишет в `game/scenes/` файл сцены (что на сцене, куски дорожек актёров, картинок и
  камеры, метки, музыка, ожидания, разговоры, переходы) и рядом SVG её актёров; картинки и звуки, которых у игры нет,
  копируются в её `pictures` и `sounds`. Одним шагом истории, «Уже отдано так», как «Отдать экрану». Как именно
  устроен файл игры и как он рисуется — уточняется до кода части 6г; мерило — 60 кадров в секунду на 1920 × 1080.

## Что на сцене (`stage`)

- `canvas(w, h)` — размер сцены, по умолчанию 1920 × 1080; это кадр камеры при приближении 1. Фон — `background(цвет)`
  или картинка.
- Фигуры рисунка (`rect`, `circle`, `path`, `group` …) — как в `draw` персонажа: декорации, пути, маски переходов.
- `picture(id, файл, { x, y, w, h, pivot })` — PNG «Ресурсов» (или кадр полосы — не в этой версии). Без `w` и `h` —
  в своём размере.
- `actor(id, персонаж, { x, y, scale, rot, pivot, drawing, params })` — персонаж «Векторной» по пути без расширения;
  `pivot` — точка его рисунка, которая стоит в `x, y` (по умолчанию его левый верхний угол), `drawing` — какой его
  рисунок показан, `params` — его параметры.
- Порядок — порядок строк, как у частей; `above` и `below` в `scene` меняют его, как у частей (4а).
- Ошибки — со строкой, как у `draw`: нет персонажа или картинки, два одинаковых `id`, `/` в `id`.

## Что происходит (`scene`)

- **Части сцены**: `part("ёжик")` — актёр целиком, `part("лес")` — картинка, `part("дорога")` — фигура,
  `part("ёжик/head")` — часть актёра; `actor("ёжик")` — тот же актёр, у него ещё `:part("head")`, `:play`, `:loop`,
  `:stop`. Свойства и переходы — все, что у частей персонажа (место, поворот, масштаб, наклон, прозрачность, видимость,
  тон, вспышка, маска, крепление, путь, копии) по тем же правилам; `actor(…):swap("air", 0.2)` — смена рисунка (4д).
- **Клип актёра**: `actor("ёжик"):play("walk", { speed, params, blend })` — клип персонажа с этого мига, строка ждёт
  его длину (`spawn` — не ждёт); `:loop("walk")` — повторяет его, пока актёру не скажут другое (`play`, `loop`,
  `stop`) или сцена не кончится, строка не ждёт. Клип пишется у персонажа: в сцене его блоки видны бледно, «К коду»
  открывает персонажа. Свой переход сцены по части актёра ложится поверх клипа, как связь сверху (шаг 1).
- **Камера**: `camera()` — свойства `x`, `y` (точка сцены в середине кадра), `zoom`, `rot`; `:center_on(часть или
  { x, y }, с, сглаживание)`; `:along("путь", с)`; `:follow(часть)` — держит её в середине, пока не скажут
  `:follow(nil)` или другое; тряска и прочее — свои модули (`require`), как у персонажа. Без вызовов камера стоит в
  середине сцены, приближение 1.
- **Музыка и звуки**: `music("имя", { fade, volume })` — музыка игры с этого мига под всей сценой, `music(nil, { fade
  })` — тишина; `sound("шаг")` — как у персонажа. На таймлайне — строки с волной (3в).
- **Переходы**: `transition("сдвиг" | "приближение" | "растворение", с, { from = "лево" … })` — первой строкой `scene`:
  как сцена входит поверх того, что было (кадр игры или последний кадр прежней сцены); `leave(…)` — последней строкой:
  как она уходит в игру. Свой переход — функция: `transition(function(old, new) new.x(-1920, 0):to(0, 0.6)
  old.opacity(0, 0.6) end)`; у `old` и `new` свойства места, поворота, масштаба, прозрачности и `mask("фигура")` по
  фигуре сцены (круг, который растёт).
- **Ожидание и разговор**: `wait_action(["Действие"])` и `talk("разговор")` — время сцены стоит до действия игрока или
  конца разговора. Во вкладке это флажки без длины; плеер по умолчанию идёт сквозь них, переключатель «Ждать, как в
  игре» останавливает его на них до клавиши действия или ▶.
- **Метки**: `emit("имя")` в сцене — сообщение «Логике» в свой миг, как метки клипа (5а).

## Вкладка

То, чем сцена отличается от персонажа; остальное — как у персонажа (разделы «Вкладка (шаг 3)» и шаги 4–5 движения).

- **Список «Сцены»** в левой панели рядом с «Персонажами»: имя, размер, длина; «Новая сцена» (код с `canvas` и одной
  строкой `scene`). Дерево частей сцены: актёры (с их частями внутри), картинки, фигуры, камера.
- **Просмотр**: большой — вся сцена с рамкой кадра камеры; малый, на месте пиксельного — **«Через камеру»**, что видит
  игрок в этот миг, с переходом. Пиксельного просмотра, запекания и «Отдать шаблону…» у сцены нет; «Снимок кадра» и
  «Отдать игре» есть.
- **Мышь**: актёр, картинка и фигура тянутся, как часть (3б), и пишут код сцены; часть актёра тянется так же —
  своим переходом сцены. Рамка камеры тянется в части 6б.
- **Таймлайн**: дорожки «актёр · свойство», «камера · свойство»; клип актёра — блок «ёжик · walk» на всю длину клипа
  (начало тянется, длина — нет: она у персонажа), его дорожки частей бледно под ним; повтор — полосой до конца;
  переходы сцены, ожидания, разговоры и музыка — своими строками.

## В игре

- **«Логика»**: нода действия **«Показать сцену»** (сцена, «Мир на паузе» — да, «Можно пропустить» — да, параметры) с
  выходом «Когда кончилась»; событие **«Сцена кончилась»** (какая, пропущена ли); метки сцены — сообщения.
- **Luau**: `forge.scene.play("Вступление", { pause, skip, params })`, `forge.scene.stop()`,
  `forge.scene.going()` — имя идущей или `nil`. Ошибки — со строкой, как у `ui.svg_play`.
- Сцена входит своим переходом, играет по своим часам (идут и при паузе мира), ждёт действий и разговоров, её музыка
  заменяет музыку игры, пока она идёт; уходит своим `leave` и возвращает игре её музыку.
- **Живой экран меню**: у экрана «Интерфейса» настройка «Сцена позади» — сцена повторяется под экраном, пока он
  показан (заставка главного меню).

## Порядок работ

Каждая часть — отдельный PR со своим разделом «Как сделано» здесь и своим уточнением до кода.

- **6а «Сцена и актёры»**: файлы сцены, список «Сцены», `stage` (`canvas`, фигуры, `picture`, `actor`), части сцены
  и актёров, `play`, `loop`, `stop`, смена рисунка актёра, запись с клипами актёров во времени, просмотр сцены,
  дерево, мышь, таймлайн, история.
- **6б «Камера и переходы»**: `camera()` и её вызовы, «Через камеру», рамка камеры мышью, `transition`, `leave`, свой
  переход.
- **6в «Звук, ожидание и разговор»**: `music`, строки музыки, `wait_action`, `talk`, «Ждать, как в игре».
- **6г «Сцена в игре»**: «Отдать игре», файл сцены игры и как он рисуется, нода, событие, Luau, пауза мира, пропуск,
  музыка, ожидание действий, разговор поверх сцены, переходы из игры и в игру, сцены подряд, «Сцена позади»,
  сохранения, пакет игры.

## Готовность

Часть готова, когда проверено всё в её пункте «Проверки», CI зелёный на Linux и Windows, раздел «Как сделано» дописан,
а PR прошёл независимую проверку. Сливает PR не автор. Прежние тесты, самопроверки, игры, шаблоны и сохранения не
тронуты.

## Проверка

- **Юнит-тесты**: `stage` (размер, порядок, ошибки со строкой); запись сцены с клипом актёра со сдвигом во времени —
  кадр сцены в миг t равен кадру клипа в t − начало; `loop` до следующего вызова; свой переход сцены поверх клипа;
  камера: матрица кадра против посчитанной вручную (сдвиг, приближение, поворот, путь, слежение); переходы: доли
  старого и нового в начале, середине и конце; ожидания и разговоры — время сцены стоит, повторы идут.
- **Самопроверка `scene`** мышью и клавишами, две игры из шаблона «Платформер»: сцена набрана с клавиатуры; актёр,
  картинка и камера тянутся, текст файла после каждой правки равен ожидаемому; Ctrl+Z / Ctrl+Y байт в байт; кадры
  «Через камеру» равны эталону; **`scene-again`** — другой процесс из другой папки видит то же; вторая игра и шаблон
  байт в байт.
- **Игра** по `--edits`: «Логика» показывает сцену; кадры экрана в заданные миги против вкладки (как 5в); ожидание
  стоит до действия; разговор поверх сцены; пропуск из меню паузы; музыка сцены и возврат музыки игры; сцена подряд за
  сценой с переходом; время кадра на 1920 × 1080.
- Порча кода по ключевым местам, полный набор Linux, CI на Linux и Windows.

## Не в этой версии

- Кат-сцена в мире игры (герой, объекты уровня, камера игры) — по рекомендации вопроса 1, своей моделью после шага 7.
- Свой текст в сцене (`Txt`), видео (`Video`) и вывод сцены в видео; разделённый экран камеры.
- Кадры полосы «Покадровой» как картинка сцены; сцена внутри сцены.
- Размытие и тень на экране игры — как у персонажа, до GPU-слоя (в просмотре вкладки они есть).
