# Картинки каталога шаблонов

Каталог `games/templates.json` называет шаблоны окна «Новая игра из шаблона» редактора: название, описание,
модуль, папку игры шаблона и картинку карточки. Картинки лежат здесь.

- `old-mine.png` (480×270) — кадр самой «Старой шахты» сразу после начала новой игры. Снят игрой из сборки и
  уменьшен вдвое:

  ```
  forge_slice --play --screenshot old-mine-full.png --frames 90 --size 960x540 --user <временная папка>
  python3 -c "from PIL import Image; Image.open('old-mine-full.png').convert('RGB').reduce(2).save('old-mine.png', optimize=True)"
  ```

- `platformer.png` (480×270) — кадр «Платформера» на первом уровне «Луг», у первого жука. Снят так же, абсолютным
  путём к папке игры (с относительным `--data` картинки HUD не находятся, это известное ограничение):

  ```
  forge_slice --data $PWD/games/platformer --play --at 33.5,-1 --screenshot platformer-full.png --frames 60 --size 960x540 --user <временная папка>
  python3 -c "from PIL import Image; Image.open('platformer-full.png').convert('RGB').reduce(2).save('platformer.png', optimize=True)"
  ```

## Шаблон «Платформер» (14.2d)

Папка игры шаблона — `games/platformer`: три уровня со своими плитками («Луг», «Холмы», «Вершина»), шаблоны героя,
«Жука», «Ежа», «Монетки», «Шипов», «Ряда шипов», «Флага» и «Указателя», связи, HUD, окна победы и поражения. Автор
правит её копию во вкладках редактора, как любую игру. Сама папка в репозитории собирается из источников:

- `platformer/assets/картинки/*.png` и их `.meta` — «Ресурсы» шаблона, их копирует в новую игру «Новая игра»;
- `platformer/tiles.png` — плитки уровней: клетка 32 px, 16 клеток в ряд, без полей, id 256…271 по порядку;
- `games/slice/{kinds,verbs,ideas}.json` — файлы модуля.

```
forge_editor --make-template platformer games/platformer
```

собирает её заново. Папка собирается рядом, в `<папка>.сборка`, и занимает место прежней, только когда собрана
целиком: если источника не хватает (например, нет `tiles.png`), команда пишет, чего нет, выходит с кодом 1, а прежняя
папка остаётся как была. Самопроверка редактора `forge_editor --self-test platformer-template` собирает её во
временные папки с русскими именами (функцией и командой из другой рабочей папки) и сравнивает с репозиторием байт в
байт, без учёта концов строк (в клоне на Windows они CRLF), так что правка источника без пересборки папки видна сразу.

Размеры, кадры и опорные точки картинок заданы в ТЗ на изображения (`/mnt/project-files/step14/14.2d-ТЗ-картинки.md`).
**Сейчас все картинки шаблона — заглушки**, сделанные `tools/platformer_template/make_placeholders.py`: фигуры
нужных размеров, кадров и опор, обведённые пурпурной рамкой, с буквой «З» в углу (у плиток только буква). Это не
законченный арт; готовые картинки заменяют их файл в файл, после чего папка собирается командой выше.
