# Макет для проверки размеров экрана игрока (13.2)

Два экрана, нарисованных для 1920×1080:

- `проверка_hud` — HUD поверх игры («растёт»). Монеты прибиты к правому
  верхнему углу, полоска сердец к левому нижнему, кнопка «Сумка» к правому
  нижнему, надпись «середина экрана» к середине по ширине. Безопасная зона
  40 px.
- `проверка_сумка` — окно по кнопке («целиком», полосы цвета #0a0e14 по
  краям). Окно стоит в середине, в нём сетка вещей героя (3 ряда видно,
  11 вещей игры прокручиваются), у ячейки «Картинка предмета» и нажатие
  «взял {item.id}», кнопка «×» закрывает окно.

Главное меню — свой экран игры `main_menu`.

Файлы собирает тест `tests/test_ui_design.cpp` («the screens for checking
screen sizes»), так что они всегда совпадают с тем, что пишет редактор.
Пересобрать: `FORGE_WRITE_EXAMPLES=1 forge_tests -tc="*checking screen sizes*"`.

## В редакторе

1. Скопировать четыре файла `проверка_*.json` и `проверка_*.html` в папку
   `game/ui/` своего проекта (рядом с `main_menu.json`).
2. Вкладка «Интерфейс», экран «Проверка: HUD». Над холстом переключатель:
   «Макет», 1280×720, 1920×1080, 2560×1440, «21:9 · 2560×1080»,
   «4:3 · 1440×1080».
   - На 21:9 холст шире, монеты и «Сумка» у правого края, надпись в середине,
     сердца у левого нижнего угла.
   - На 4:3 экран выше: сердца и «Сумка» у нижнего края, масштаб 75 % (пишется
     над холстом).
   - Слои на этих размерах выбираются щелчком, но не двигаются: правка слоёв
     идёт в «Макете».
3. «Проверить» на каждом размере. Кнопка «Сумка» нажимается там, где видна,
   и открывает окно. Окно стоит в середине; на 21:9 полосы слева и справа,
   на 4:3 сверху и снизу. Сетка прокручивается колесом. Щелчок по ячейке
   пишет в панели «Сообщение «Логике»: взял …» с id именно этой вещи.
4. Вернуться в «Макет», закрыть и открыть экран снова: слои, их места и
   номера те же. Ctrl+Z и Ctrl+Y правок, сделанных в «Макете», работают и
   при выбранном другом размере.

## В игре

`--size ШИРИНАxВЫСОТА` задаёт окно игры (в точках системы: при масштабе
Windows 150 % пикселей в 1,5 раза больше) или картинку прогона без окна
(в пикселях). Сколько пикселей у экрана на самом деле, игра пишет в журнал:
`экран игрока: 2560×1080 пикселей`.

Из сборки разработчика (`build/apps/slice`), с копией данных игры, где эти
экраны лежат в `ui/`:

```
forge_slice --data <копия games/slice с проверка_* в ui/> --size 2560x1080
forge_slice --data <...> --size 1440x1080
```

Упакованная игра (`cmake --build build --target forge_slice_package`):
скопировать четыре файла в `build/dist/OldMine/data/game/ui/`, затем

```
OldMine --size 2560x1080
OldMine --size 1440x1080
OldMine --size 1280x720
```

Пока герой не подобрал ни одной монеты, HUD пишет «Монеты: {inv.coins}» как
есть: так сейчас выглядит любой текст со значением, которого ещё нет.

Автотест того же правила без окна, на любом размере:
`forge_slice --test --scene menu --size 2560x1080` (шаг «экран другого
размера»: экраны «растёт», «целиком», «растянуть», угол и нажатие).
