# Поведение окон (13.11)

Главное меню, экран над игрой и два окна. На них видно, где окно появляется,
ставит ли оно игру на паузу, закрывается ли по Esc и затемняет ли то, что под
ним.

Страницы в `ui/` — те самые файлы, что пишет редактор: их собирает тест
`tests/test_ui_design.cpp` («the example of windows' behaviour is as the
editor writes it»), а самопроверка редактора (шаг 152) открывает их, меняет,
отменяет и сверяет, что файлы остались байт в байт теми же. Пересобрать:
`FORGE_WRITE_EXAMPLES=1 forge_tests -tc="*example of windows*"`.

## Экраны

- `окна_меню` — главное меню («показывать: меню»):
  - «Настройки» открывает `окна_настройки`;
  - «Играть» начинает новую игру.
- `окна_игра` — поверх игры:
  - «Настройки» открывает `окна_настройки`;
  - «Монета» считает `demo.coins`, по ней видно, доходит ли щелчок.
- `окна_настройки` — окно как новое из редактора: «Везде», «Закрывается по
  Esc», «Затемнять то, что под окном», плюс «Пока открыто, игра стоит».
  Кнопки:
  - «Громче» считает `demo.volume`;
  - «Справка» открывает `окна_справка`;
  - «Закрыть» закрывает окно.
- `окна_справка` — окно «Только над игрой», Esc его не закрывает, без
  затемнения и без паузы. Стоит справа, рядом с кнопками настроек. «Понятно»
  закрывает его.

## В редакторе

1. Скопировать восемь файлов из `ui/` в `game/ui/` своего проекта.
2. Вкладка «Интерфейс», экран «Окна: настройки», ничего не выбрано, вкладка
   «В игре». Должно быть так:
   - «Где появляется»: «Везде»;
   - переключатели: пауза, Esc и затемнение включены;
   - «Что его открывает»: кнопка «Настройки» главного меню (над главным
     меню) и кнопка «Настройки» экрана над игрой (над игрой).
3. Экран «Окна: справка»: «Только над игрой», Esc и затемнение выключены.
   Его открывает кнопка «Справка» окна настроек. Строка говорит, что
   справка откроется, только если окно настроек над игрой.
4. «Проверить» на «Окна: меню»: «Настройки» открывает окно над меню, а
   «Справка» в нём не открывается (журнал говорит почему). Esc закрывает
   окно, второй Esc заканчивает проверку.
5. «Проверить» на «Окна: игра»:
   - «Настройки» открывает окно, справка встаёт над ним;
   - щелчок по «Громче» рядом со справкой доходит до окна под ней;
   - Esc справку не закрывает;
   - «Понятно» закрывает справку, Esc — окно настроек.

## В игре и в пакете

Самопроверка игры читает эти файлы с диска той же `GameScreens::load`,
которой игра читает свою `game/ui` при запуске:

- из сборки разработчика: `forge_slice --test --scene windows` читает
  `games/examples/window-behaviour/ui`;
- из пакета: `forge_slice_package` кладёт эту папку в
  `data/examples/window-behaviour`, и `OldMine --test --scene windows` читает
  её оттуда.

```
cmake --build build --config Release --target forge_slice_package
build/dist/OldMine/OldMine --test --scene windows
```

На Windows игра без консоли, поэтому вывод и код выхода удобнее взять так
(PowerShell):

```
$p = Start-Process build\dist\OldMine\OldMine.exe -ArgumentList '--test','--scene','windows' `
       -Wait -PassThru -RedirectStandardOutput okna-out.txt -RedirectStandardError okna-err.txt
$p.ExitCode
```

Код 0 и `self-test passed` в выводе — шаги прошли. Ещё в выводе строки
`self-test: «…»` по шагам и `пример окон читается из …` (папка, откуда
прочитаны страницы). Если что-то не так — `[error] self-test: …` и код 1.
С `--window` то же идёт в окне, а журнал пишется в
`%TEMP%\forge_game_offscreen\log.txt`.

Шаги проверки с мышью и клавишами игрока (события идут, как их отдаёт окно
игры: экранам и оболочке, а что они не взяли — миру):

1. «пример поведения окон с диска»: четыре страницы прочитаны из файлов,
   других экранов нет. Меню примера стоит вместо меню игры.
2. «окна над главным меню»:
   - Tab и Enter на «Настройки» открывают окно над меню, окно берёт
     клавиатуру;
   - Enter на «Громче» работает;
   - «Справка» над меню не открывается;
   - удержанный Esc закрывает окно один раз, клавиатура возвращается к
     «Настройки»;
   - Tab и Enter на «Играть» начинают игру.
3. «окна в игре»:
   - герой идёт вправо, щелчок по «Монета» доходит;
   - «Настройки» открывает окно: затемнение видно, мышь над ним, а не над
     миром, щелчок по «Монета» не доходит;
   - клавиша игры (2, ячейка) до мира не доходит, герой стоит, хотя «вправо»
     держат;
   - «Громче» мышью и пробелом работает;
   - «Справка» встаёт над окном, щелчок рядом с ней доходит до «Громче»;
   - Esc при справке сверху: обе остаются, открывается пауза игры;
     удержанный Esc паузу не закрывает;
   - на следующем кадре пауза видна и стоит над обоими окнами (а перед ней
     был щелчок по нижнему окну): мышь над «Продолжить» паузы, щелчок по
     «Понятно» справки под паузой не срабатывает;
   - «Журнал» и «Настройки» паузы открываются над окнами, мышь над их
     кнопками; Esc из настроек — обратно в паузу;
   - щелчок по «Продолжить» возвращает в игру: оба окна на месте, справка
     над окном, меню игры над обоими, клавиатура снова у «Громче»;
   - J открывает журнал над окнами, J ещё раз — обратно в игру;
   - «Понятно» закрывает только справку; щелчок по «Громче» единственного
     окна, затем J: журнал над этим окном, мышь над его кнопкой;
   - удержанный Esc закрывает окно;
   - фокус возвращается туда, где был; клавиша 2 снова меняет ячейку,
     мышь на пустом месте снова над миром, щелчок по «Монета» доходит,
     герой снова идёт.

## Руками

Самопроверка не заменяет человека: щелчки и клавиши в ней подставляет
программа. Проверить руками в игре: скопировать папку `data/game` пакета
(или `games/slice`) и положить в её `ui/` восемь файлов примера, затем
запустить `OldMine --data <эта папка>`. Меню примера встанет вместо меню
игры; дальше те же шаги мышью и клавиатурой.
