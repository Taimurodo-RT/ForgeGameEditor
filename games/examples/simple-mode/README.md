# Пример «Простого» режима (13.3)

Два экрана, собранных только из блоков «Простого» режима:

- `простой_hud` — поверх игры: текст «Монеты: {inv.coins}», полоска сердец
  (hero.hearts из hero.hearts_max) и кнопка «Сумка», которая открывает окно
  `простой_сумка`.
- `простой_сумка` — окно по кнопке: заголовок, список вещей героя (ячейка с
  картинкой предмета, его названием и количеством) и кнопка «Закрыть».

Файлы собирает тест `tests/test_ui_simple.cpp` («the example screens»), так
что они всегда совпадают с тем, что дают блоки. Пересобрать:
`FORGE_WRITE_EXAMPLES=1 forge_tests -tc="ui simple*"`. Игра встраивает оба
экрана в свою самопроверку (`forge_slice --test`, шаг «экраны из простых
блоков»), в том числе в собранной игре OldMine.

## Свой экран с нуля, за пять минут

1. Вкладка «Интерфейс». Над холстом переключатель «Простой / Полный»:
   выбрать «Простой». Вместо инструментов рисования появятся блоки:
   Кнопка, Текст, Картинка, Полоска, Список.
2. «Новый экран» в списке экранов слева. Справа — «Когда видно»: «Всегда,
   поверх игры» для HUD, «Окно: открывает кнопка» для окна.
3. Щёлкнуть блоки. Каждый ложится на свободное место ближе к середине и
   сразу выбран. Справа только нужное: название, надпись или текст, размер
   букв, цвет (или цвет темы игры), картинка, «Сколько / Из скольких» у
   полоски, «Вещи героя / Задания» у списка, место и «Держится» (к какому
   краю прижат на экране другого размера).
4. У кнопки «При нажатии»: «Открыть экран» (и какой), «Закрыть этот экран»,
   «Настройки», «Новая игра» и другие действия игры.
5. «Проверить»: экран оживает на данных игры, кнопка нажимается, внизу пишется,
   что она сделала. Ctrl+Z / Ctrl+Y отменяют и возвращают каждое изменение,
   по одному шагу на действие.

## Этот пример в редакторе

1. Скопировать четыре файла `простой_*.json` и `простой_*.html` в папку
   `game/ui/` своего проекта (рядом с `main_menu.json`).
2. «Интерфейс», режим «Простой», экран «Простой: HUD». Выбрать кнопку
   «Сумка»: «При нажатии — Открыть экран: простой_сумка».
3. «Проверить», нажать «Сумка»: открывается окно, в списке по ячейке на
   каждую вещь героя. «Закрыть» закрывает окно.
4. Переключить на «Полный»: те же слои с теми же номерами, все свойства на
   месте. Обратно на «Простой»: ничего не меняется и не добавляется в историю.

## Экран, нарисованный в «Полном»

Его можно открыть и править в «Простом». То, чего простая панель не
показывает (движение, обводка, тени, маска, копия компонента, несколько
действий и т. п.), не удаляется и не заменяется: внизу панели написано, что
скрыто, и ссылка «Открыть в «Полном»». Простая правка меняет только своё
свойство.
